# 待确定参数

两台 M2006 控制腕部俯仰和旋转；一台 GO 控制机械臂角度；气泵用于气动夹爪。

| 类别 | 待确定内容 | 填写位置/用途 |
| --- | --- | --- |
| 电机与驱动 | GO 完整型号、C610 型号、供电范围、ID | 核对铭牌与协议；`FML/motor/motor_cfg.h` |
| 机械臂传动 | GO 输出轴正方向、外部传动比 | `arm_motor_per_joint`，带符号 |
| 腕部传动 | 齿轮齿数、左右方向、俯仰/旋转对应关系 | `wrist[2][2]`，由 CAD 计算后实测 |
| 零位 | 三轴零位姿态、标记位置、回零传感器预留 | 当前手动捕获，机械零位统一定义为三轴 0° |
| 行程 | 三轴最小/最大角，旋转时气管与线束允许范围 | `axis[].min_deg/max_deg` |
| 运动能力 | 三轴及腕部输出轴最大速度、加速度 | `axis[]`、`wrist_motor_*` |
| 负载 | 臂长、部件质量、重心、物料质量 | 校核驱动力矩与保持能力 |
| M2006 闭环 | 位置 Kp、速度 Kp/Ki/Kd、电流及速度上限 | `mechanism_board_config.h`；台架后带载标定 |
| GO 闭环 | 协议 Kp/Kd、带载保持误差 | `mechanism_board_config.h`；先核对转子侧增益 |
| 气泵 | 电压、启动电流、驱动模块、GPIO、有效电平 | `MECH_PUMP_*` |
| 阀与气缸 | 阀板型号/接口、单/双线圈、通道、开合掩码、失能状态 | `MECH_VALVE_*` |
| 气路反馈 | 工作压力、夹紧/张开时间、到位开关或压力传感器 | 气路验收及后续动作完成条件 |
| 联动目标 | 腕部相对角或末端绝对姿态，两俯仰轴几何关系 | 明确保持水平的角度换算 |
| 验收 | 定位误差、重复精度、动作时间、保持温升 | 台架记录与整机验收 |

机械参数填写在 `APL/mechanism/mechanism_config.c`。默认映射、行程及运动能力为 0；填好后设置 `motion_confirmed=true`，并填写有效电机增益。腕部限幅使用两台电机减速器输出轴的单位，不包含内部 36:1 减速比。

气路填写在 `APL/mechanism/mechanism_board_config.h`，确认接线、引脚复用和失能状态后设置 `MECH_PNEUMATICS_CONFIRMED=1`。泵 GPIO 默认未分配，阀开合掩码默认未分配。

初期软件默认值：机构任务 5 ms，反馈超时 100 ms，手动租期 2000 ms，M2006 电流上限 1000 raw（C610 约 1 A）、速度上限 60 输出轴 rpm。电机增益默认 0。实际机构采用的限值由台架和带载测试确认。
